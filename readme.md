# psycho - Sony PlayStation 1 emulator

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

## Introduction

psycho is an in-development [Sony PlayStation 1](https://en.wikipedia.org/wiki/PlayStation_(console))
emulator written in the [C programming language](https://en.wikipedia.org/wiki/C_(programming_language))
targeting the [C17 ISO/IEC 9899:2018](https://en.wikipedia.org/wiki/C17_(C_standard_revision)) standard.

This is not suitable for production usage in any way, shape, or form at this
time. If you want a production quality PS1 emulator, use [DuckStation](https://www.duckstation.org/).
